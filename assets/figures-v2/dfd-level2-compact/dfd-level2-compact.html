Full flow names and parent mapping

One image per Level 1 process. Each external entity and data store appears once per image. Separate writes or reads by different child processes can realize the same parent flow; they are independent arrows, not new features. Printed labels use the full names listed below. Logs, schedules and Daily Tasks remain Head Laboratory only; the chatbot is informational Q&A only.

2.3: Class Representative on-schedule requests require assigned Faculty approval. Out-of-schedule requests go to the available assigned Faculty, or directly to Dean when that Faculty is unavailable. The selected reviewer makes the final decision. Faculty out-of-schedule requests require Dean only; scheduled Faculty activities need no additional approval. 2.4 saves the final decision; rejection releases the hold. 4.2 retrieves only finally authorized reservations for issuance.

1.3: Head Laboratory creates the Faculty account first and issues its credentials to Faculty. Faculty manually supplies verified representative name, Student ID and section to Head Laboratory. 1.4 uses those details and the existing Faculty reference to create or manage one active representative account per section. 1.5 generates representative credentials for Faculty handover. Representatives sign in using their Student ID and generated password. Existing accounts may be managed without creating a new Faculty account.

5.1 stores scheduling information in D3 Laboratory Schedule. 5.2 automatically records completed reservations and reconciled returns in D11 Laboratory Usage Logs, containing the completed Physics and Circuits Laboratory Logs. Partial returns do not independently complete or duplicate a session. Head Laboratory reviews these logs. 5.6 maintains Daily Tasks separately. 5.4 compiles reporting metrics only from D11 completed usage logs; 5.5 uses those metrics to generate the End-Term Report for the selected laboratory and term. The report contains Average Equipment Use, Top 5 Equipment & Consumables, Laboratory Frequency Usage and Recent Activity. Reservation Summary, Borrowing Slip Data and Inventory Summary are not direct inputs to 5.4. D2 and D5 still supply completed-session information to 5.2, and D5 still supplies borrowing evidence to 5.3 for clearance. D3 scheduling records, Daily Tasks, disposal and outstanding clearances are excluded from the report. If a required metric value is missing from the usage logs, the report identifies the missing data rather than inventing a value.
