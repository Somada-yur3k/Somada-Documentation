# Swimlane account hand-off preview

- Head Laboratory remains responsible for creating/updating accounts using verified details.
- Faculty receives the issued credentials and gives the Class Representative their credentials.
- Added distinct Class Representative actions: receive credentials from Faculty, then log in with issued credentials.
- Existing accounts retain the no-setup path; the remaining reservation/approval responsibilities are unchanged.
- Following the requested adviser presentation convention, Faculty rejection, Dean rejection and clearance-status branch endings now use Flow Final (circle/X). The lower report ending retains Activity Final (bullseye). This does not mean application shutdown or that every branch runs before reporting.
- Tests verify the hand-off order, lane ownership, one initial/one activity final/three flow finals, connected orthogonal routes, visible final arrow shafts, and no connectors crossing unrelated shapes.

Local preview only: shared database drafts, live documents and deployment are not changed.
