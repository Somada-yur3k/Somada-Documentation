# Activity ending symbols — adviser convention

Original layouts and connectors are retained. All individual branch endpoints use Flow Final (circle with X), except these existing connected lower endpoints retained as the single Activity Final:

| Diagram | Retained Activity Final |
| --- | --- |
| User Access & Accounts | Account management outcome |
| Reservations, Availability & Approvals | No permitted operation selected |
| Laboratory Questions | Read answer |
| Equipment & Borrowing | No permitted operation selected |
| Laboratory Administration & Reporting | Report display/export |

The catalogue success/error, issue, return, disposal and insufficient-history outcomes now use Flow Final. No new common-end lines, merge bars or changes to the operation selection logic were introduced. One Initial Node is retained per diagram.

This is the requested presentation convention, not a claim that the bottom branch executes after all others or that an Activity Final shuts down the application. Existing exclusive branches remain independent alternatives. Shared database drafts are not overwritten; this updates authored templates and publication images only.

Supersedes the reverted common-final experiment. Swimlane is unchanged.
