04 / Approved scope

What this system does

  • Request & approvalFaculty submits scheduled activities. Class Representatives submit on-schedule or out-of-schedule requests. Dean is approval-only.
  • Laboratory operationsHead Laboratory and assigned staff manage inventory, issuance, returns and disposal. Only Head Laboratory manages logs, schedules, daily tasks and clearance.
  • Informational Q&AClass Representatives and Faculty ask about items, schedules, operating hours and their own reservation status. No AI reservation actions or generated report summaries.
  • Inventory ForecastingHead Lab reviews next-month consumable restock estimates and potential reusable-equipment shortages from existing actual usage and stock. Dynamic recommendations only; insufficient history is explicit. No automatic purchasing or stock changes.

06 / Method & evidence

Transparent measurements

Feature trace coverage
Fully linked main use cases ÷ all main use cases. A link requires a full description, matching actor set and event coverage, backlog references, and the expected directional Level 2 exchanges.
Artifact availability
Available current artifacts ÷ six planned artifact categories: Documentation, Use Case, DFD 0, DFD 1, DFD 2, ERD. The five Level 2 images form one category. Available does not mean finalized.
Model checks
Passing automated checks ÷ all defined checks for that model. Each check and source link is listed below. The ERD draft receives “Pending” until semantic validation; no schema completeness score is claimed.
Recorded implementation
Backlog items marked Done or Completed ÷ all backlog items. This uses the paper’s recorded status; it does not inspect or certify application code.
Limits
Structural matching does not prove every business rule is correct. Pending consultation items remain separate blockers even if all automated checks pass. Crossing connectors are permitted under the existing layout decision; print legibility still needs a physical-paper review. This audit reads local website sources, not the live Google Doc.
